title=Minimal Display Bars + Nutritions + Discomfort [B41/B42]
description=[b]Minimal Display Bars Nutritions (Build 42 Compatible)[/b]
description=
description=This mod builds upon the original Minimal Display Bars by introducing [b]Stress[/b], [b]Lipids[/b], [b]Proteins[/b], [b]Carbohydrates[/b], and a new [b]Discomfort Level[/b] tailored for Build 42.
description=
description=[h1]Key Features:[/h1]
description=
description=1. [b]New Stress Level Bar[/b]
description=
description=   * A [b]Stress Level Bar[/b] has been added, which also accounts for stress caused by smoking cigarettes.
description=   * Even if the stress value exceeds [b]1[/b] due to smoking, it will be capped at [b]1[/b] for visual clarity.
description=   * [i](Coming Soon!)[/i] The bar will include [b]dual coloring[/b] to distinguish the stress caused by cigarettes from the base stress level.
description=
description=2. [b]Additional Bars[/b]
description=
description=   * Added [b]Lipids[/b], [b]Proteins[/b], and [b]Carbohydrates[/b] to the original mod.
description=   * Added a new [b]Discomfort Level[/b] bar specifically adapted for Build 42.
description=   * Added a [b]Sickness[/b] bar and a [b]Wetness[/b] bar.
description=
description=3. [b]Enhanced Save System[/b]
description=
description=   * The save system has been changed from [i]getModFileWriter[/i] to [i]getFileWriter[/i] (reader included).
description=   * Configuration files are stored in the [i]User/Zomboid/Lua[/i] directory.
description=   * To avoid issues with the writing method in Build 42, the mod configuration is now saved in [b].txt[/b] format instead of [b].lua[/b].
description=   * The configuration file generated by the mod is:
description=
description=     * [code]MOD Config Options (MinimalDisplayBarsNutritions)B42.txt[/code] for Build 42.
description=     * [code]MOD Config Options (MinimalDisplayBarsNutritions).lua[/code] for Build 41.
description=
description=4. [b]Load and Share Presets[/b]
description=
description=   * A [b]"Load Preset"[/b] option has been added.
description=   * You can easily load a preset shared by another player.
description=   * Simply place the preset file in the [i]User/Zomboid/Lua[/i] folder and rename it to:
description=     [code]MDB_Preset.txt[/code]
description=   * Presets shared in the older [code]MDB_Preset.lua[/code] format are still loaded, so there is no need to convert them.
description=   * The preset system allows you to easily share your preferred mod configuration with friends.
description=
description=5. [b]Export Your Configuration[/b]
description=
description=   * Use the [b]"Export Preset"[/b] option to export your current mod settings.
description=   * The mod will automatically create an [code]MDB_Preset.txt[/code] file in the [i]User/Zomboid/Lua[/i] directory.
description=   * You can then share this file with other players, who can load it using the [b]"Load Preset"[/b] option.
description=
description=6. [b]Bug Fixes[/b]
description=
description=   * Fixed the vanilla thirst bug that could cause the thirst value to become incorrect or glitchy after drinking.
description=   * [i]This fix is no longer required on Build 42.1.0 and later, as the issue has been fixed in the vanilla game.[/i]
description=
